# Scientific Software Research Collaboration — Sanitized Case Study

## Context

Research collaboration with experimental researchers on Python tooling for crystallographic lattice-orientation reconstruction and visualization from electron-microscopy workflows.

## Engineering contribution

- Worked across scientific data handling, numerical computation, package integration and interactive visualization.
- Applied linear algebra and geometric transforms to convert between lattice/orientation representations.
- Integrated workflows involving ASE and abTEM.
- Debugged numerical and integration issues and documented limitations and expected behavior.
- Iterated with research users to turn open-ended experimental needs into reproducible software workflows.

## Publication boundary

This case study intentionally does not reproduce third-party, unpublished or collaborator-owned source code. Where the underlying contribution is public/open-source, the canonical upstream repository should be linked directly once the exact project URL and contribution history are confirmed.

## Transferable themes

Scientific Python, numerical validation, reproducibility, research-user communication, package integration, geometry/linear algebra and maintainable tooling.
