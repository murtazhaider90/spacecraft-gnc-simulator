# Baseline Performance Record

This document records measured results for the current baseline implementation. Values below are generated by the repository scripts and are not hard-coded into the simulator.

## Verification environment

- Python runtime: containerized Linux execution environment
- Integrator: fixed-step RK4
- Plant step: 0.02 s
- Nominal simulated duration: 40 s
- Controller: quaternion PD, `kp = 4.0`, `kd = 18.0`
- Reaction-wheel torque limit: 1.0 N m per axis
- Reaction-wheel momentum limit: 8.0 N m s per axis
- Star-tracker update period: 0.2 s
- Navigation: gyro propagation + quaternion complementary correction

## Test suite

The verification suite contains **19 tests** spanning quaternion math, 6-DOF propagation, analytic translation checks, actuator saturation, navigation correction, invalid-input handling and closed-loop requirements.

The measured statement coverage for `src/gnc` is **100% (333/333 statements)**. The exact report is retained in `artifacts/coverage.txt`.

## Nominal case

Nominal initial condition: 20 deg attitude offset about body Y, zero initial body rate, deterministic sensor-noise seed 7.

| Metric | Measured value | Target |
|---|---:|---:|
| Final attitude error at 40 s | **0.145 deg** | < 0.2 deg |
| Settling time to <1 deg for 2 s | **9.58 s** | < 30 s |
| Peak applied body torque | **1.000 N m** | <= 1.0 N m |
| Peak wheel momentum | **1.910 N m s** | <= 8.0 N m s |
| RMS attitude-estimation error | **0.0225 deg** | < 0.2 deg |

A report-plot script (`examples/generate_performance_plot.py`) can regenerate the nominal response figure locally.

## Monte Carlo robustness campaign

A total of **90 randomized simulations** were executed across three independent seeds (7, 17 and 27), 30 runs per seed. The campaign varies initial attitude/rate, inertia, gyro bias/noise, star-tracker noise, estimator initialization and constant disturbance torque as defined in `docs/REQUIREMENTS.md`.

| Metric | Aggregate result |
|---|---:|
| Settling success rate | **100.0% (90/90)** |
| Final error median | **0.224 deg** |
| Final error p95 | **0.401 deg** |
| Final error maximum | **0.720 deg** |
| Settling time median | **9.51 s** |
| Settling time p95 | **10.64 s** |
| Settling time maximum | **19.48 s** |
| RMS estimation error p95 | **0.0861 deg** |
| RMS estimation error maximum | **0.117 deg** |
| Maximum applied torque | **1.000 N m** |
| Wheel momentum p95 | **2.661 N m s** |
| Maximum wheel momentum | **3.274 N m s** |

The canonical aggregate summary is retained in `artifacts/monte_carlo_aggregate_90.json`. Raw per-run CSV output is generated by the benchmark script and intentionally ignored by Git to avoid accumulating transient benchmark files.

## Deterministic boundary matrix

Six explicit stress cases were also run to complement the randomized campaign. All six settled and finished below 1 deg. Four cases use 35 deg initial errors on principal/diagonal axes. Two extension cases deliberately exceed the Monte Carlo envelope:

- 45 deg diagonal initial error with 0.3 deg/s initial rates and 0.004 N m disturbances: **18.90 s settling, 0.0646 deg final error**.
- 60 deg Z-axis initial error with -0.4 deg/s initial rate and -0.004 N m disturbance: **12.72 s settling, 0.187 deg final error**.

The complete matrix is retained in `artifacts/scenario_matrix.json`.

## Runtime reference

Five nominal 40 s simulations were timed in the local execution environment. Median wall-clock time was **1.36 s**. This is an environment-specific reference only, not a real-time-performance claim.

## Interpretation

The current baseline demonstrates stable attitude capture, explicit actuator saturation, robust navigation correction and reproducible verification under the selected uncertainty model. The strongest evidence is not any single final-error number but the consistency of the closed loop across randomized and deterministic cases while respecting actuator limits.

The model remains intentionally limited: no orbital environment, flexible-body modes, actuator dynamics beyond torque/momentum saturation, wheel desaturation, thruster allocation or EKF. Those are documented extensions rather than hidden omissions.
