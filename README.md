# Engineering Portfolio Workspace

Private staging workspace for engineering and software portfolio projects referenced across my CV variants.

The repository is organized around reproducible implementations, verification assets, and sanitized engineering case studies. Personal projects include runnable source and tests. Employer/research work is documented only at a non-confidential level; proprietary source, unpublished data, and employer IP are intentionally excluded.

## Engineering standard

Each implementation is expected to include:

1. A clearly stated engineering objective and assumptions.
2. Reproducible setup instructions.
3. Verification or test coverage appropriate to the project.
4. Explicit limitations and separation between measured data, simulated data, and demonstration data.
5. No fabricated experimental results, performance metrics, or proprietary material.

## Case studies

Sanitized case studies cover selected thermal/airflow engineering, UAV systems integration, Formula Student aerodynamics, and scientific-software research collaboration. They document engineering process and transferable methods without publishing confidential or third-party source code.
